# Dengue data in Peru from 2019 to 2022.

This dataset contains yearly dengue cases from 2019 to 2022.

## Usage

``` r
dengue_peru
```

## Format

A dataframe object with 171281 rows and 8 variables:

- departament:

  name state

- province:

  name of province

- district:

  name of distric

- dengue_type:

  dengue type

- year:

  year of cases

- week:

  week of year

- age:

  age of case

- sex:

  gender
