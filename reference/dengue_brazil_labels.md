# Brazil Dengue Dataset 2000-2019 labels

Data dictionary/variable-label reference table accompanying the Brazil
Dengue Dataset 2000-2019, documenting field names, codes, and
descriptions used across microregion, mesoregion, state, region, biome,
and ecozone identifiers, as well as climatic and demographic variables
in the main dataset.

## Usage

``` r
dengue_brazil_labels
```

## Format

A dataframe object with 26 rows and 4 variables:

- variable:

  variable name

- long_name:

  long variable name

- description:

  variable description

- source:

  source
